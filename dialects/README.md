# لهجات المجتمع

الحزم هنا بتعلّم زول كلمات وجُمل من لهجات السودان المختلفة. أي زول يستعمل زول يقدر يضيف.

- **من التطبيق:** درّب زول على كلامك (دربني / علّمني)، وبعدها قول «زول شارك لهجتي»، واختار «رسّلها للمجتمع».
- **من GitHub:** أضف ملف `اسم-الحزمة.txt` بنفس شكل `sudan-everyday.txt`، وسطر ليهو في `index.txt`.

شكل الملف:

```
# زول: حزمة لهجة
# الاسم: اسم الحزمة
[كلمات]
الكلمة البتتقال=الكلمة المقصودة
[عبارات]
الجملة البتتقال=الأمر البيفهمو زول
```
